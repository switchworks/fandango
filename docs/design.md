# fandango の設計 — closed-form DSP

`README.md` から分離した技術資料。バンドル全体の設計軸と、各プラグインの
代数的な中身・実測値を置く。数値はすべて実測に基づく。

---

## 設計哲学 — closed-form DSP

バンドル全体を貫く統一軸は**「代数閉形式 (closed-form) で詰め切った DSP」**。ヒューリスティック・LUT・経験的パラメータに頼らず、挙動が数式で証明できる形まで代数で詰める。

- **線形系**（`:spread` `:raindrop` `:velvet` `:rotate`）では**完全線形**として現れる — spread は測定誤差 -130 dB・L/R 対称誤差 0.0、rotate は振幅特性が全周波数で厳密に 1
- **非線形系**（`:crush` `:nice-bulk` `:finalist`）では**閉形式 ADAA** として現れる — 波形整形は本質的に非線形だが、シェイパーの不定積分を閉形式で解き、除算・分岐・しきい値なしの代数構造で実装する。crush は量子化関数の閉形式積分 `F(x) = Δ(m·x - Δ·m²/2)`
- この帰結が「安全・破綻しない」— 有界性・DC 除去・エイリアシング抑制が、実装の副産物でなく**証明可能な性質**として得られる

*closed-form DSP — no heuristics, no lookup tables, provable behavior.*

## `:spread` — 純粋線形ステレオワイドナー

**核心: 代数閉形式で詰め切られた完全線形 M/S ゲインスケーリング**。ヒューリスティック・LUT・cubic 補間・FFT・心理音響補正、一切なし。「シンプルなミニマル実装を代数で勝ちに行った」設計哲学の継承。

### 特徴

- **完全線形** — 測定誤差 -130 dB、フィルタ皆無、純粋 2×2 定数行列
- **有理関数カーブ** `K(t) = 4 / (3 - 2t)` — Mid/Side ゲインが IEEE float 丸めレベル（1e-7）でフィット。設計者が代数で解いた曲線
- **全帯域フラット、L/R 対称完全**（誤差 0.0）
- **Inverse / Center** — 処理本体と数学的に直交する拡張モード
- **Bass Preserve**（60 / 100 / 150 / 200 Hz、独自追加） — 低域を触らずに高域だけ広げる。マスタリング実用性大
- **CPU 極軽量** — 1 サンプル 4 乗算 + 2 加算のみ

### 音の性質

- 位相破綻しにくい — 0.5–0.75 域は K(t) カーブの緩勾配で穏やかに広がる、これは偶然でなく設計仕様
- 挿しただけで音が壊れる感触が無い、透明な広がり
- Wide 側で急加速する広がり感、Center モードで無限に近い拡張

### 想定用途

マスタリング、ミックス最終段、ステレオ画像リカバリ、モノ素材のステレオ化補助。

### なぜこれが特筆に値するか

「シンプル = 安っぽい」という商業圧力の中で、Side ハイパスや心理音響補正で "見栄え" を装うのではなく、**代数的に閉形式解を導き最小構成で実装しきった稀有例** を、現代の nih-plug スタックで再構築したもの。位相破綻しない・全帯域フラット・CPU 極軽量、その全てが「数学で詰めた結果として自然に得られる」性質。

## `:raindrop` — どこにも収まらない極短窓 FX

エコーというよりダブラー、ダブラーというより短窓リバーブ。**61–80 ms の極短窓**で、Mid コアで発音を中央に落とし込みつつ、Haas シャッフルで周囲に空間の影を広げる、**二層構造のショート FX**。

### 特徴

- **極短窓ディレイ** — 61–80 ms、リバーブより速く通常のディレイより遅い「隙間の帯域」
- **完全線形** — 測定誤差 -140 dB
- **Mid コア + Haas シャッフル** — エコー音は中央、空間感は周辺で発生する二層構造
- **常にほんのり生きている** — 最小 feedback は 0 でなく 0.15、完全無音にならない
- **WIDTH ノブ**（独自追加） — 0% = モノコアエコー、100% = 左右独立エコーで原音ステレオ画像を継承

### 音の性質

- ダブラーとリバーブの中間、どちらとも違う独特の質感
- ボーカル・ギターに挿すと「厚みが 1 段深くなる」感触
- 短窓のため「明確な繰り返し」ではなく「音が半歩ずれて重なる」

### 想定用途

ボーカル / ギターのダブリング、シンセの厚み、ドラムループのスラップ、コーラス代替。

## 他プラグイン概要

### `:gate`
16 ステップ × 3 状態（Trig / Hold / Rest）、Duty / Attack / Cut 制御。Trig 境界での stutter dip で「タタタ」感を維持。ホスト BPM 追従、三連対応（1/8T, 1/16T）。

**ゲート曲線は無状態の閉形式。** `gate_curve(steps, pos, duty, edge, shape)` は絶対ステップ座標 `pos` の純関数で、内部状態もエンベロープフォロワも持たない。同じ `pos` には常に同じ値が返るため、**ブロック分割で出力が変わらない**（`a4_block_split_invariance`。DAW のバッファサイズや分割位置に依存しない）。

エッジ形状は Möbius 位相ワープ `W(x) = x / (x + s(1−x))` を `sin²(πW/2)` に噛ませたもので、`shape` が `s = 2^(2·shape)` を動かして立ち上がりと立ち下がりの偏りを連続に変える。片側エッジ幅は `2w = edge·duty ≤ duty ≤ 区間長` が無条件に成立するので、**場合分けなしに両エッジが区間内へ収まる**。

保証されているのは次（すべて単体テストで機械判定。gate 35 本）:

- **値域 0..1 は `sin²` の値域そのもの**で、clamp を使っていない。区間内部は数値評価ではなくリテラル `1.0` の代入
- **全 Trig + `duty = 1.0` は bit-exact 恒等**、`depth = 0` も恒等。`shape` / `edge` をどう振っても破れない
- **全 Rest は厳密に無音**（`0.0`）。エッジ端点は厳密（`rise(0) = 0`, `rise(1) = 1`）でエッジ内は単調
- 同期は Bar / Song / Note の 3 モード。Bar では小節頭で位相が厳密に 0 に戻る。ホストが再生位置を渡さない場合は内部で拍を進めて継続する
- **GUI はアナライザではない。** 入力信号にも再生位置にも反応せず、パラメータだけから決まる 1 周分の `gain(φ)` を描く。拍線も `step_length` だけで決まる

### `:drawl`
F1/F2 共振 2 段直列（声道の全極モデル）の連続母音モーフ、Q ジッタでレトロ着色。市場に類例極めて少ない擬似ボーカルフォルマント系。

正規化は **never-boost 不等式**。総合特性の振幅ピークを閉形式（2 次共振のピーク角周波数 `w_i·√(1−1/(2Q_i²))` での候補点評価）で求め、`|H(jw)| ≤ 1` に収まるスカラを掛ける。したがって**電力は入力を超えない**（実測: 全域走査での最大超過 +0.046 dB）。旧実装は白色雑音の全帯域電力を 1 に揃える**等式**だったため、素材スペクトル次第でブーストし得た（実素材で真ピーク +19 dB）。

- **真ピークは保証対象外。** `|H| ≤ 1` はインパルス応答の L1 ノルム分の余地を残すため、時間領域の真ピークはこの不等式では縛られない（実測は informational で最大 -1.99 dB。母音位置 0〜4 を 0.5 刻み・`jitter` 0/1 の全点、実素材 `OPLL Organ` 4.8 s / 44.1 kHz、4x 窓付き sinc）。
- **母音により出力は下がる。** 実素材で RMS ゲイン U -5.99 / O -11.91 / A -20.25 / E -14.91 / I -6.06 dB。後段でゲインを足して使う。
- **母音間の音量差は残る。** 上記の開きは約 14.3 dB。スカラ正規化は周波数非依存なので相対スペクトル形状は変えられず、母音差は正規化では消せない。
- **Q ジッタは音量を揺らす。** ピークを 1 に固定するので通過帯域幅の変化がそのまま出る。`jitter = 1` で幅 5.6 dB（代数上限 5.8 dB）。

**drawl が保証するのは「持ち上げないこと」であって「音量が動かないこと」ではない。** 母音を変えたときの出力レベルは、素材スペクトルとフォルマント配置の内積で決まる**観測量**であり、制御対象ではない — 音量を揃える契約は drawl ではなく後段（ゲイン段 / リミッタ）が持つ。`:finalist` が真ピークを持たないのと同型の線引き。

これは方針ではなく代数の帰結である。出力電力は `E_v(P) = s_v²·∫P(f)|H_v(f)|²W(f)df` で、これを全ての素材 `P` について母音 `v` 非依存にする条件は「全ての `f` で `|H_v(f)|` が母音によらない」、すなわち母音でスペクトル形状が動かないこと。**母音フィルタである限り、素材を見ずに音量を揃える静的な方法は存在しない**（`W` に聴感重みを置いても同じ）。白色雑音では開きが 1.5 dB に収まり、傾いた素材で開くのは、この式そのものの帰結。

**使い方の注意:**

- **出力は必ず下がる。後段でゲインを足す前提の設計。** 母音により -6〜-20 dB。挿しただけで音量が揃うことは無い。
- **後段にリミッタ（`:finalist`）を置くと、レベル回復と母音間の音量差の圧縮が同時に効く。** 実測（`input` +24 dB / `ceiling` -1.0 dB / `drive` 0 / `release` 100 ms、素材 4 種）で出力 -8.6〜-13.8 dBFS、母音間の開き 14.3 dB → **1.5〜4.3 dB**。`input` +18 dB でも大半は縮む。
- **母音間の音量差は母音の順位そのものが素材で変わる。** 出力レベルは素材スペクトルとフォルマント配置の内積で決まるため、下降傾斜の素材では F1 の低い母音（U / I）が大きく、ボーカル素材では逆転することがある（実測: OPLL Organ 音源は `U>I>O>E>A`、あるボーカル素材は `O>E>A>U>I`）。母音ごとの後段ゲインを固定値で決め打ちしない。

### `:trip-delay`
L タップ 2/8 拍、R タップ 3/8 拍の非対称 2 タップディレイ。単純な ping-pong と一線を画す、シンコペーション + 三連的リズム感の同時発生。ホスト BPM 追従。

**非対称なのはタップ位置だけで、帰還の周期は L/R 共通に 3/8 拍。** したがって L の反射列は 2/8 起点には並ばず、3/8 周期の上に 2/8 のタップが乗る形になる。これが「三連的」の実体であり、実装の取りこぼしではない（2026-08-30 に設計として確定）。

遅延線長は較正値ではなく閉形式。最長タップは対応最低テンポ 60 BPM での 3/8 拍なので `ceil(sr·60/60 · 3/8) + 64` サンプルで足り、全サポートレートで最長タップが clamp されないことをテストで確認している。

**`level` ノブは無音まで連続。** UI 値 `v` に対し `v ≥ K` では `−24 … −9 dB` の指数写像そのもの、`v < K` は線形フェードで 0 へ繋ぐ。膝幅 `K = 1/(10^(SPAN/20) − 1) = 0.2163` は「膝が、この写像が既に出しているゲイン変化率を超えない」という条件から**一意に決まる**（`SPAN = 15 dB` のみで決まり、下端 dB に依らない）。膝の瞬間傾き 0.5822 は可動域の最大傾き 0.6127 を下回る。

膝を入れる前は `v → 0+` で `−24 dB` から一段で無音へ落ちており、`SmoothingStyle::Linear` がターゲット `0.0` へ厳密到達するため **Level を最小まで下げるだけで可聴なクリックを踏んだ**（実測 −30.4 dBFS、220 Hz 正弦・振幅 0.5・120 BPM・feedback 0.30。フルスケール素材で −24.4 dBFS）。`v ≥ K` では旧写像と bit-exact に一致する。

### `:velvet`
ヴェルベットノイズ（疎な ±1 インパルス列）による完全線形デコリレータ。spread（定常 M/S 像）とも raindrop（聴こえるショート FX）とも直交する、10–50 ms の「聞こえない広がり」枠。width / length / color の 3 パラメータ。フィードバック皆無で無条件安定。

**インパルス列は固定シードから決定論的に生成する。** L / R のシードは実測で選定した固定定数で、既定（width 35% / length 30 ms）における 1/3 oct 平均からの**最大偏差 1.157 dB**（60 候補中の最良）。モノ加算したときに櫛状の谷を作らないための選定であり、シードを変えるとこの性質が壊れるため変更禁止としている。`length` は 10 / 20 / 30 / 40 / 50 ms の 5 段で、全段ぶんの列を事前生成しておく。

**wet 単体の RMS を入力等価に正規化する。** 正規化係数はタップ包絡から閉形式で決まる `1/√(Σ g(m)²)`。ただしこれは疎 FIR の部分しか見ておらず、後段の `color`（1 極 LP）が持つエネルギー損失が計上されていなかった時期がある。現在は LP 分も折り込み済みで、既定 `color = 0` では `alpha = 0.9270509`、補償係数 `√((2−alpha)/alpha) = 1.0758154`（+0.6348 dB）。補償が wet 経路にだけ掛かり dry は無改変であることを f32 精度（誤差 ~1e-7）で全サンプル確認している。

**`width = 0` は bit-exact 恒等。** フィードバック経路が存在しないため、パラメータをどう振っても発振しない。定常部の出力サンプル列を基準値として固定し、意図しない音の変化を検出できるようにしている（velvet 18 本）。

### `:rotate`
1 次オールパスセクションを 2 / 4 / 6 / 8 段縦列し、位相のみを回転させるフェーズローテータ。振幅特性は全周波数で厳密に 1（完全線形・全帯域フラット）、音色・音量エネルギーを一切変えずに非対称波形（ボーカル・ベース・ブラス）のピークだけを下げる。リミッター前段でゲインリダクション削減を狙う地味系ツール。stages / freq (50–2000 Hz) の 2 パラメータ、100 % wet 固定（dry と混ぜるとコムフィルタ化する存在意義破壊のため MIX を持たない）。フィードフォワード状態 1 個/段のみで無条件安定 — 本バンドル中最も安全な実装。放送業界で数十年の実績がありながら商用単体プラグインがほぼ空白の技術枠。

### `:crush`
mid-tread 量子化器に 1 次 ADAA (Antiderivative Anti-Aliasing) を適用した、**濁らないローファイ**ビットクラッシャー。市販ビットクラッシャーの大半がエイリアシング放置で濁る問題を、量子化関数の閉形式不定積分 `F(x) = Δ(m·x - Δ·m²/2)` 経由の 1 次差分で解決。bits (1.0–16.0 連続) / rate (S&H 1.0–32.0 連続) / mix の 3 パラメータ。ステートレス（履歴 1 サンプル・フィードバック無し）で発振リスク皆無、bits=4 の非高調波成分がナイーブ実装比 10 dB 以上抑制（実測 10.68 dB @ 1046.5 Hz, fs=48k）。S&H も区間平均で段を非整数時刻へ置く（2026-08-28）。段の値をサンプル区間の時間平均で読むため、1 次 ADAA が量子化器に対してしていることと同じ演算を S&H に対して行う形になり、非整数 rate で余分な像が 11.8–28.2 dB 減る（rate 1.0–2.0 では完全に消える）。整数 rate では混合項が `δ=0` で式から消えるので旧実装と bit 一致する。代償は 1 サンプルのレイテンシ（`set_latency_samples(1)` で報告）。rate パラメータは実効レートの刻みを対数軸で等間隔にするため `log2(rate)` で保持する。時変系 ADAA そのものは未対策のまま。

### `:tilt`
Baxandall 型ティルト EQ。低 / 高シェルフを pivot 周波数中心に対称連動させ、gain 1 ノブで音色をシーソー反転する完全線形フィルタ。既製 Tilt EQ にほぼ無い pivot 周波数 (100–5000 Hz) と slope 可変化を持ち、「歪み系の後段整音・シリーズ全体の潤滑油」枠を埋める。

低シェルフに `−g`、高シェルフに `+g` を与えて pivot を軸に振る。非線形要素は一つも無く、シェルフ biquad 2 段のみ。

**係数計算は f64 で行い、最後に f32 へ落とす。** DC 応答 `(b0+b1+b2)/(1+a1+a2)` などが微小和の商になるため、pivot 下端 100 Hz（`ω0 ≈ 0.013`）では f32 のままだとキャンセレーションで相対誤差が 1e-3 級まで劣化する。処理そのものは Direct Form I。

保証されているのは次（48 kHz・テストで機械判定。tilt 16 本）:

- **`gain = 0` は恒等**。997 Hz の振幅誤差 < 1e-4
- **pivot が動かない**。700 Hz における低 / 高シェルフの合成ゲインは `gain = ±6 / ±12 dB` のいずれでも偏差 < 0.5 dB
- **傾きが対称**。`±6 dB` を与えたとき pivot から等距離の 100 Hz 側と 4900 Hz 側で、傾き量の差 < 0.5 dB
- **全端点で安定**。`gain` ±12 dB × `pivot` 100 / 5000 Hz × `slope` 0.3 / 1.0 の全組み合わせで、インパルス応答が 1 秒後に `|y| < 1e-6` へ収束する

### `:nice-bulk`
Bass (≤150 Hz) / Hi (≥4 kHz) 帯域を LR4 3-way クロスオーバーで分離し、帯域別のパワーロー・アップワード圧縮で量感を持ち上げる。`bass_amount` / `hi_amount` の 2 ノブのみ。低域・高域の帯域別ダイナミクス処理という路線を代数閉形式で構成した。倍音付加ではなく帯域別ダイナミクス処理という設計に転換した、旧 `:excite` の後継（`:excite` は退役し `attic/` へ凍結）。

ノブは「その帯域を上げる量」。式の構造から次が**恒等式として**保証される — ゲインが 1.0 を下回らない（上げて音量が下がらない）、ノブに対し単調増加、0% で完全恒等、上限有界。出力段は閉形式 1 次 ADAA ソフトサチュレータ（`:crush` と同型）。

**使い方の注意:**

- ノブは**小レベル成分ほど強く持ち上げる**ため、上げるほどコンプ感（ダイナミクスの平坦化）が出る。`bass` は 50% 前後までが素直に効く領域で、それ以上はコンプ感が出やすい
- **効き量は素材のスペクトルに依存し、bass と hi で体感差が出る。**これは仕様。ゲインは帯域内エンベロープと較正点（bass 0.5 / hi 0.25）の比で決まるため、その帯域のエネルギーが較正点を上回る素材では持ち上げ幅が頭打ちになる。素材によって bass が強く効いたり hi が強く効いたりする
- ブースト分だけ出力レベルは上がる。0 dBFS を超える場合は後段のフェーダーで下げる（プラグイン内でリミットするとトランジェントが失われるため、意図的にそうしていない）

### `:finalist`
Lookahead リミッタ + 閉形式 ADAA ソフトクリップのマキシマイザ。`input` で押し込み、`ceiling` で止め、`release` を選ぶ。lookahead は 2.5 ms 固定（ノブ化しない）。

**2.5 ms という値は「100 Hz でゲインリップル歪が消える最小の窓長」である。** ゲイン経路の総インパルス応答長は peak-hold `N` + min-hold `N-1` + boxcar 2 段 `2N-2` で `4N-3` サンプルあり、これが 1 周期を覆う正弦ではゲインが定数になって歪が厳密に消える。よって歪ゼロの下限周波数は `f_min ≈ sr/(4N)`、ms 表記で `lookahead ≈ 250/f_min`。実測（48 kHz、amp 0.5、`input` +12 dB、`ceiling` -1.0 dB、THD 2〜20 次）で THD が 0 になる最小 `N` は 50 Hz で 237、100 Hz で 119、200 Hz で 61、400 Hz で 31 サンプルと、この閉形式に ±1.5 % で一致する。2.5 ms = 120 サンプル @48 kHz は 119 のすぐ上、すなわち 100 Hz をリップルフリーにする下限そのもの。

| lookahead | `N` @48k | `D = 2N-2` | 50 Hz THD | 100 Hz THD | 200 Hz THD | 1 kHz THD |
|---|---|---|---|---|---|---|
| 0.25 ms | 12 | 0.46 ms | 3.383 % | 1.777 % | 0.769 % | 0.0006 % |
| 0.50 ms | 24 | 0.96 ms | 3.111 % | 1.388 % | 0.376 % | 0.0002 % |
| 1.0 ms | 48 | 1.96 ms | 2.421 % | 0.664 % | 0.036 % | 0.0002 % |
| 1.5 ms | 72 | 2.96 ms | 1.722 % | 0.256 % | 0.000 % | 0.0002 % |
| **2.5 ms** | **120** | **4.96 ms** | **0.728 %** | **0.000 %** | **0.000 %** | **0.0002 %** |
| 4.0 ms | 192 | 7.96 ms | 0.091 % | 0.000 % | 0.000 % | 0.0002 % |
| 6.0 ms | 288 | 11.96 ms | 0.000 % | 0.000 % | 0.000 % | 0.0002 % |

トレードオフは**低域のリップル歪と遅延の 2 者だけ**である。天井保証は全 `N` で成立し（正弦・ノイズ・バースト各素材で `max|out|/ceiling` = -0.000009 dB）、1 kHz 以上の THD と過渡時のゲイン下降量・復帰時間も `N` に依存しない。

**天井保証は構成上の定理であって、attack/release のヒューリスティックではない。** 出力ゲインは、有限窓 min-hold `g_min` の非負・係数和 1 の FIR 平滑（boxcar 2 段）による**凸結合**であり、各項が `ceiling / p[n-D]` 以下になる。この条件から総群遅延 `D = 2N-2`（`N` = lookahead 窓長）が**一意に定まる**。よって出力サンプルピークは `ceiling` を 1 サンプルも超えない。実測でも全条件でちょうど `ceiling` に一致する（誤差 1e-6、f32 の丸めを吸収する内部マージン分）。

`drive = 0` で多項式ステージは厳密恒等、かつ `ceiling` 未満の信号にはゲインも恒等 — **挿しただけでは遅延以外に何も起きない**。`drive` は 3 次ソフトクリップ `s(u) = (3u - u³)/2` の 1 次 ADAA で、`f_k(u) = u + k·(s(u) - u)`。

**ADAA は非線形残差 `s(u) - u` にだけ掛ける。** 線形項 `u` はエイリアスを生まないうえ、これを ADAA に通すと差分商が `(u + u_prev)/2` になり信号全体にローパスが掛かる（減衰量は `|Δu|`、すなわち高域成分の量に比例する）。残差だけに掛けることで `k = 0` は場合分けなしに厳密恒等になり、`k → 0` も連続になる。エイリアス抑制は落ちない（11 kHz・amp 1.4・`k = 1` の折返し成分で、全体 ADAA との差 ≤ 0.13 dB、ADAA 無しに対しては 16 dB の抑制）。

**`drive` はレベルを上げる。これは仕様であり、この整形族の恒等式である。** `f_k(u) = u(1+k/2) - (k/2)u³` より静的ゲインは `f_k(u)/u = 1 + (k/2)(1 - u²)`（`|u| ≤ 1`）で、小信号では `20log10(1 + k/2)` dB、`k = 1` で **+3.52 dB**。`|u| = 1` では `k` に依らずゲイン 1。奇数 3 次で「原点の傾き 1」と「クリップ端で 1」を同時に課すと `s(u) = u` しか残らないため、この持ち上がりは 3 次ソフトクリップを選んだことの必然であって補正すべき誤差ではない。ゲイン補償は入れていない — 補償が消せるのは原点 1 点だけで、素材によって符号すら変わる実効ラウドネス差は消えず、「どの規準で 0 dB に揃えるか」という素材依存の自由度を新たに持ち込むため。**`drive` を動かしたときのラウドネス比較は `input` で揃えてから行うこと。**

実測（48 kHz、`ceiling` -1.0 dB、`release` 80 ms、`k = 0` を基準とした出力 LUFS-I 差）:

| 素材 / `input` | k=0.25 | k=0.5 | k=0.75 | k=1.0 |
|---|---|---|---|---|
| 1 kHz 正弦 / 0 dB | +0.823 | +1.590 | +2.296 | +2.949 |
| 1 kHz 正弦 / +12 dB | +0.330 | +0.787 | +1.473 | +2.534 |
| 220 Hz AM + 1.7 kHz / 0 dB | +0.914 | +1.743 | +2.499 | +3.194 |
| 220 Hz AM + 1.7 kHz / +12 dB | +0.484 | +1.031 | +1.653 | +2.225 |
| ホワイトノイズ / 0 dB | +0.501 | +0.999 | +1.489 | +1.968 |
| ホワイトノイズ / +12 dB | +0.008 | -0.006 | -0.015 | -0.020 |

押し込むほど差が縮むのはリミッタが吸収するため。同じ条件の THD（2〜20 次）は 1 kHz 正弦 `input` +12 dB で `k = 0.25` の 4.9 % から `k = 1.0` の 28.5 %。

**`ceiling` はサンプルピーク基準で厳密。** 真ピーク（インターサンプルピーク / dBTP）は別の契約で、finalist の管轄ではない — PCM サンプルピークの天井は finalist が持ち、再構成真ピークの天井は配信エンコーダ / 別のラウドネス段が持つ。

真ピークを finalist に持たせない理由は 2 つあり、どちらも設計の根幹に触れる。(1) `ceiling` に指定した値とサンプルピークが一致しなくなる（真ピークを守るためにサンプルピークを下げる必要があるため）。(2) **`ceiling` 未満の信号に何もしないという恒等性が崩れる** — サンプルピークは `ceiling` 未満だが真ピークだけ超える信号でゲインが 1 でなくなるため。**finalist はノブの値がそのまま出て、`ceiling` 未満では何も起きないほうを選んでいる。**

4x オーバーサンプリング（ITU-R BS.1770-4 準拠の補間）で測った `ceiling` 比の真ピーク超過（48 kHz、`ceiling = -1.0 dB` 既定）:

| 素材 | `drive` | 超過 |
|---|---|---|
| 1 kHz 正弦, `input` +12 dB | 0.0 | -0.00 dB |
| 1 kHz 正弦, `input` +12 dB | 1.0 | +0.62 dB |
| 11 kHz 正弦 | 0.0 | +0.29 dB |
| 11 kHz 正弦, `input` +12 dB | 1.0 | +2.60 dB |
| fs/4 正弦・位相 45°（理論最悪）, `input` +12 dB | 0.0 | **+3.10 dB** |

fs/4・位相 45° の正弦はサンプル値 0.707 に対し真ピーク 1.0 で、**サンプルピーク基準の定義から出る理論上限 +3.01 dB** そのもの。トーナル素材でこれ以上は出ない。

**使い方の注意:**

- **配信納品の最終段には真ピークリミッタを別途置く。** finalist はその前段（トラック / バス / 2mix）で使う設計
- `ceiling` 既定は -1.0 dB。0 dBFS まで詰めたい場合でも、上表の超過分を見込んで選ぶ
- `bypass` は遅延した dry をそのまま返す。切替の前後でも天井保証は成立する（`tests/bypass.rs`）

## `:nimbus` — 有限支持の初期反射

**センドバスに置く装置。** 初期反射だけを生成し、後部残響を持たない。`mix` 100% が既定なのは、
dry と混ぜる装置ではなく**送って戻す**装置だからで、控えめな設定として選ばれた値ではない。
送り -18 dB を前提に較正されている。

### 仕組み

仮想室（7.19 × 5.41 × 3.23 m、壁面反射係数 0.55）の鏡像法から、3 次までの反射のうち
到達の早い 16 本を幾何 tap として閉形式で算出する。受音点は 0.28 m 離した 2 点で、
L/R の遅延差・振幅差は室の幾何から一意に決まる。**tap の位置・本数・ゲインに調整可能な自由度は無い。**

拡散段はベルベットノイズ（疎な ±1 インパルス列、密度 2000 個/秒）。包絡は
`exp(-ln10·3·t / T60)` に 200 ms から `cos²` テーパーを掛け、300 ms で厳密にゼロへ落とす。
振幅の正規化係数 `A` は定数ではなく、Parseval からフィルタ通過後の総エネルギーを
目標値に一致させる**閉形式の従属量**として決まる。

wet 側のハイパスのコーナーも定数ではない。`f_hp = 2000·√(T_room / V)` — 直方体室のモード密度と
共振半値幅からモーダルオーバーラップ 3 を課して導かれ、この室では 87.81 Hz。

`distance` は tap 時刻を `1 / (1 + 1.5·r)` でスケールし、wet ゲインを `r` で、
高域チルトを最大 -9 dB（4 kHz）で連動させる。遠ざかるほど直接音と初期反射の時間差が縮む、
という物理をそのまま写している。

フィードバックは無い。ディレイラインの変調も無い。

### 保証

- `mix = 0` で bit-exact 恒等。dry は高域シェルフもハイパスも通らない
- 幾何 tap と拡散段の支持長は有限。300 ms 以降は早期 return による**厳密ゼロ**であり、
  指数減衰の裾ではない
- 系の極は wet 側の biquad 2 個のみ。フィードバックが無いため無条件安定
- 総エネルギーは閉形式で正規化される。素材にも時間にも依存しない

### 実測

盲検 ABX（48 kHz、K 加重ラウドネス（BS.1770-4、ゲート付き）とピークを両系統で一致、
素材はピアノ / シンセストリングス / アコースティックドラム、各モノ化）:

- **dry との弁別・選好** — 送り -18 dB・`distance` 0.5・`mix` 100%。全素材で即座に弁別可能、
  選好は全素材で nimbus
- **幾何の可聴性** — 幾何 tap の遅延とゲインの対応・極性・L/R の対応**のみ**を無作為化し、
  tap 本数・ゲイン絶対値の多重集合・遅延範囲・総エネルギー・拡散段・フィルタを一致させた
  対照系との弁別。送り -18 dB、および wet が支配的になる送り 0 dB の両条件で**弁別できない**

後者は否定的な結果として記録する。**鏡像法は tap の恣意性を消すための手続きであって、
可聴な差を作ってはいない。** 音の差は、有限支持の無相関な尾・wet のスペクトル整形・
エネルギー正規化から来ている。

### 使い方の注意

- **インサートで 0 dBFS 素材に直挿しすればレベルは当然超える。** 較正の前提を外した使い方であり、
  欠陥ではない
- **素材によって知覚のされ方が変わる。** 持続音（パッド・ストリングス）では先行音効果が働かず、
  反射が見かけの音源幅に寄与して**空間**として聴こえる。トランジェント素材（ドラム・パーカッション）
  では反射が直接音に融合し、空間ではなく**質感**として聴こえる。同じ設定でも用途が分かれる
- **後部残響は持たない。** 広い場所に置く・奥行きを作る用途には応えない。管轄外であり、
  調整不足ではない
